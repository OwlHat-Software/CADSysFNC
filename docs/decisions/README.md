# Decision records

One short file per decision: the question, the options, a recommendation, and what was decided. New records start
from `0000-template.md`.

- Status: **Proposed** (waiting for Jacco) -> **Accepted** / **Rejected** -> later possibly **Superseded by NNNN**.
- Claude writes proposals; Jacco decides, by replying in the chat or by editing the status.
- Nothing is built on a proposal before it is accepted.
